# EVIL Rises project memory

The guild approved the WoW Forever theme in **EVIL Rises 0.2.11**. Read [the theme guide](THEME.md) before changing or adding UI. Carry its window, tab, table, and typography treatments into future features. Update the guide when the guild approves a change to the visual baseline.

## Development

- After implementing addon changes, automatically replace the installed `EVILRises` folder in the user's personal `World of Warcraft/_forever_/Interface/AddOns/` directory with the updated addon. Verify that the changed addon files are present in the installed copy.
- Never take control of the user's computer or interact with the WoW client. Ask the user to run `/reload` in game only after you have made addon changes and verified that those changes are present in their `_forever_` installation.
